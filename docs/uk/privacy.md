# Конфіденційність

GileaLauncher — це лаунчер Minecraft, що працює на вашому комп'ютері. У нього немає власних акаунтів, реклами, аналітики чи стеження. Тут описано, що він зберігає, що надсилає і куди.

## Що лишається на вашому комп'ютері

- **Налаштування, збірки, світи й моди** зберігаються в теках лаунчера (див. «Де зберігаються дані» в [README](../../README.uk.md#де-зберігаються-дані)).
- **Акаунти.** Для акаунта Microsoft лаунчер зберігає ваш нікнейм, UUID і токени входу, які видає Microsoft. Токени зашифровані, а ключ лежить у тій самій теці. Так їх не прочитати зі скопійованого чи комусь переданого файлу, але від людини, яка має доступ до вашого облікового запису на комп'ютері, це не захищає. Офлайн-профілі зберігають лише ім'я.
- **Логи** лаунчера й гри лежать у цих теках, доки ви їх не видалите.
- **Аварії самого лаунчера.** Якщо лаунчер аварійно закриється, він збереже коротку нотатку (текст помилки й місце в коді лаунчера, без вашої домашньої теки) у своїй теці кешу, щоб під час наступного запуску запитати, чи надіслати звіт. Нотатка зникає, щойно звіт надіслано або ви відмовились; зберігається щонайбільше п'ять найновіших, до 30 днів.

Ніщо з цього не залишає ваш комп'ютер, якщо нижче не сказано інакше.

## З ким зв'язується лаунчер

Лаунчер підключається до цих сервісів лише для того, щоб виконати ваші дії. Кожен із них бачить вашу IP-адресу, а також назву й версію лаунчера, як і під час будь-якого завантаження.

| Сервіс | Навіщо | Що отримує |
|---|---|---|
| Microsoft, Xbox Live, сервіси Minecraft | Вхід з акаунтом Microsoft, перевірка, що гра у вас є | Вхід відбувається на сторінці самої Microsoft, у вашому браузері; потім лаунчер обмінює токени, які видала Microsoft |
| Mojang (`piston-meta.mojang.com`, `libraries.minecraft.net`, `resources.download.minecraft.net`) | Версії Minecraft, їхні файли та Java для гри | Які файли завантажити |
| Fabric, Quilt, Forge, NeoForge | Версії лоадерів та їхні файли | Які файли завантажити |
| Modrinth, CurseForge | Пошук і встановлення модів, ресурспаків, шейдерів і модпаків, перевірка оновлень | Ваші пошукові запити, а також відбитки (хеші) файлів збірки, коли лаунчер шукає для них оновлення |
| GitHub | Перевірка й завантаження оновлень лаунчера | Нічого, крім самого запиту |
| mc-heads.net, minotar.net, mineskin.eu | Голови скінів біля ваших акаунтів | UUID або ім'я гравця |
| `gigabait.uk` (лише редакція TensaCraft) | Збірки серверів TensaCraft на Головній і їхні картинки за адресами, які дає сервер (лаунчер перевіряє, чи картинка змінилася) | Нічого, крім самого запиту |

Коли ви запускаєте гру, сам Minecraft зв'язується з Mojang і Microsoft згідно з [їхньою заявою про конфіденційність](https://privacy.microsoft.com/privacystatement).

## Реєстр Windows

За замовчуванням лаунчер нічого не записує в реєстр Windows: режим відеокарти — **Авто**, і відеокарту для гри обирає Windows.

Якщо вибрати **Вбудовану** чи **Дискретну** (Налаштування → Java → «Режим GPU для нових збірок» або налаштування збірки → Середовище), лаунчер спершу попередить, а тоді запише цей вибір для Java гри туди, де Windows зберігає відеокарту для кожної програми, — туди ж, куди пише сама Windows у «Параметри → Система → Дисплей → Графіка».

| | |
|---|---|
| Розділ | `HKEY_CURRENT_USER\Software\Microsoft\DirectX\UserGpuPreferences` |
| Ім'я значення | повний шлях до Java збірки (`javaw.exe`) |
| Значення | `GpuPreference=1;` — вбудована, `GpuPreference=2;` — дискретна |

- Лише розділ поточного користувача, без прав адміністратора. Нічого іншого лаунчер не читає й не змінює.
- Навіщо: на ноутбуках із двома відеокартами Windows може запустити гру на слабшій вбудованій; так їй можна сказати інакше.
- Деякі антивіруси стежать за змінами в реєстрі й можуть попередити про цей запис. Це очікувано.
- Щоб прибрати запис, поверніть **Авто**: під час наступного запуску гри лаунчер видалить записи, які зробив. Також їх можна прибрати в «Параметри → Графіка» Windows.

Інсталятор для Windows додає звичайні записи будь-якої встановленої програми (рядок у списку встановлених програм, щоб її можна було видалити). На Linux і macOS лаунчер нічого такого не зберігає: на Linux **Дискретна** лише задає змінні PRIME від NVIDIA для процесу гри.

## Звіти

Звіти стосуються самого лаунчера: щоб його проблеми можна було знайти й виправити. Звіт надсилається лише після натискання кнопки, на `gigabait.uk`:

- «Повідомити» на сповіщенні про збій операції (встановлення версії, лоадера чи модпака, оновлення лаунчера…), коли збій схожий на проблему лаунчера, а не вашої мережі, акаунта чи комп'ютера;
- «Проблема з лаунчером» у вікні «Підтримка», де ви описуєте, що сталося;
- запитання після аварії лаунчера, під час наступного запуску («Не надсилати» видаляє нотатку про аварію);
- у редакції TensaCraft: вікно помилки встановлення серверної збірки на Головній.

Звіт містить:
- текст і код помилки або ваш опис;
- версію лаунчера, систему (ОС) і недавні дії лаунчера;
- для аварії лаунчера: текст її помилки й місце в коді лаунчера;
- журнал самого лаунчера;
- ваш контакт, лише якщо ви його вказали.

Звіт ніколи не містить логів гри, краш-репортів чи файлів збірки. Коли вилітає гра, лаунчер лише відкриває ці файли для вас, на вашому комп'ютері: найчастіше причина — моди збірки, а не лаунчер.

Перед надсиланням лаунчер замінює шлях до вашої домашньої теки на `<USER_HOME>` і прибирає зі свого журналу токени входу.

Щоб видалити надісланий звіт, напишіть у [Discord](https://discord.com/invite/mftAjQA4Pp).

## Видалення ваших даних

- Видаліть акаунт на сторінці «Профілі» в лаунчері, і разом з ним видаляться його токени.
- Видаліть теки лаунчера, щоб стерти все, що він зберігає.
