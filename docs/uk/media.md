# Картинки: гілка `media`

Картинки репозиторію лежать не в `main`, а в гілці `media`. Спільної історії з `main` у неї немає, і кожен файл у ній має незмінну адресу:

```
https://raw.githubusercontent.com/TensaCraft/GileaLauncher/media/<шлях>
```

## Що там є

| Тека | Що | Хто завантажує |
|---|---|---|
| `readme/<lang>/` | банер і скриншоти README | `README.md` (`en_US`), `README.uk.md` (`uk_UA`) |
| `setup/<lang>/` | картинки майстра першого запуску (див. [development.md](development.md#картинки-майстра-першого-запуску)) | кожен випущений лаунчер, за адресою |
| `guides/` | картинки гайдів у Discord | дописи в Discord, за адресою |
| `releases/<версія>/` | скриншоти релізу | анонси релізів і вебсторінки лаунчера, за адресою |

`<lang>` — код мови інтерфейсу (`en_US`, `uk_UA`). У кожної мови ті самі назви файлів: `readme/en_US/builds.jpg` і `readme/uk_UA/builds.jpg` — це той самий скриншот двома мовами.

## Правила

- **Посилання завжди веде на гілку,** `media/<шлях>`, ніколи на SHA коміту. Тоді заміна файлу оновлює його всюди, де його показують.
- **Назва ніколи не змінюється.** Випущені лаунчери завантажують `setup/`, README — `readme/`, дописи в Discord і вебсторінки — `guides/` і `releases/`. Якщо файл перейменувати чи видалити, вони зламаються, а випущені лаунчери вже не виправиш.
- **Картинку замінюють на місці,** під тією самою назвою. Тоді всюди, де її показують, з'являється нова, і в `main` нічого міняти не треба.
- **У гілку лише додають коміти:** без rebase, amend і force-push, щоб кожна її копія лишалася робочою.
- **Лише картинки.** Скриптів та інших файлів у гілці немає.
- Повідомлення коміту — один рядок про те, що змінено (`readme: new modpacks screenshot`).

## Як замінити картинку

Працюйте в окремій копії гілки, щоб `main` лишався як є:

```bash
git fetch origin media
git worktree add ../gilea-media media
cd ../gilea-media
# покладіть новий файл замість старого, під тією самою назвою
git add readme/uk_UA/builds.jpg
git commit -m "readme: builds screenshot with the new toolbar"
git push origin media
```

GitHub покаже нову картинку за кілька хвилин: він недовго тримає файли в кеші. Discord може показувати стару трохи довше. Наостанок: `git worktree remove ../gilea-media`.

## Як додати

- **Скриншот для README.** Зніміть його всіма мовами того самого розміру, що й інші (JPEG завширшки 2400 px), покладіть у `readme/<lang>/<назва>.jpg` під однаковою назвою для кожної мови й покажіть і в `README.md`, і в `README.uk.md`.
- **Скриншот для вебсторінки чи допису** (`guides/`, `releases/<версія>/`). Знімайте його в 1200 × 750 CSS px з подвійною щільністю й зберігайте JPEG 2400 × 1500, як у README: менший не заповнює колонку сторінки. Вигляд (акцент і шрифт) — стандартний, якщо картинка не про інший.
- **Картинки майстра** змінюються лише тоді, коли змінюються картки Головної, кнопка «Грати» чи бічна панель: їх показують випущені лаунчери.
- **Мову.** У `readme/<lang>/` будуть ті самі назви, що й в інших мовах. Картинки майстра для неї лягають у `setup/<lang>/`, де лаунчер шукатиме їх, щойно матиме цю мову. README цією мовою посилається на свою теку.
