# Документація для розробників

GileaLauncher — лаунчер Minecraft на Rust: Tauri 2 відповідає за вікно й роботу з системою, Leptos (WebAssembly) — за інтерфейс. У коді немає бренду. Назва, ідентифікатор, адреси й набір модулів беруться з профілю збірки в `build-profiles/`.

| Документ | Про що |
|---|---|
| [development.md](development.md) | вимоги, команди, профілі, коміти й git-хуки |
| [architecture.md](architecture.md) | крейти, шари, теки даних, мережа, бренд |
| [modules.md](modules.md) | модулі: бекенд, інтерфейс, провайдери вмісту, новий модуль |
| [testing.md](testing.md) | тести та їхні правила, Linux у WSL, перевірка оновлень |
| [releasing.md](releasing.md) | версії, редакції, пакування, релізи на GitHub |

Для гравців: [README](../../README.uk.md) у корені репозиторію і [privacy.md](privacy.md) — що лаунчер зберігає й надсилає.
