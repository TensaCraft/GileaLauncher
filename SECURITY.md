# Security policy

## Supported versions

Only the latest release gets security fixes. The launcher updates itself, so please check that you
run the newest version before you report.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately instead:

1. On the repository's **Security** tab, press **Report a vulnerability**.
2. Tell us the launcher's version and your system, what you did, what happened, and what an attacker
   could do with it. Steps to reproduce help the most.

You will get an answer within 7 days. Once a fix is released, the advisory is published, with credit
to you if you want it.

## Повідомити про вразливість

Не створюйте публічну issue про проблему безпеки. Надішліть звіт приватно: вкладка **Security**
репозиторію → **Report a vulnerability**. Напишіть версію лаунчера, систему, що ви зробили, що
сталося й чим це небезпечно.
Відповідь — протягом 7 днів.
